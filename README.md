# 영근록 靈根錄

생년월일시의 사주팔자를 계산하고 오행 구조를 선협식 영근으로 판별하는 한국어 웹 애플리케이션입니다. 유희적 용도로만 사용합니다.

## 실행

Node.js 20.9 이상이 필요합니다.

```bash
npm install
npm run dev
```

`http://localhost:3000`에서 확인할 수 있습니다.

```bash
npm test
npm run lint
npm run build
```

## 배포

`main` 브랜치에 푸시하면 GitHub Actions가 테스트와 정적 빌드를 실행한 뒤 GitHub Pages에 자동 배포합니다.

- 공개 사이트: <https://kz2g1ew-commits.github.io/yeonggeunrok/>
- 배포 방식: Next.js static export (`out/`)
- 민감한 입력값은 URL, GitHub 또는 호스팅 서버에 전송하지 않음

## 기술 구성

- Next.js 16.2.12, React 19, TypeScript, App Router
- Tailwind CSS 4
- `lunar-typescript` 1.8.6 (MIT): 양·음력/윤달, 절기표, 입춘·절입 기준 팔자
- Luxon 3.7.2 (MIT): IANA 시간대 정규화
- Vitest 4

계산은 클라이언트에서 실행됩니다. 생년월일시는 서버, 데이터베이스, 쿠키, `localStorage`에 저장하지 않으며 결과 URL에도 넣지 않습니다. 결과 페이지 새로고침 시 브라우저 메모리의 결과가 사라지는 것이 의도된 동작입니다.

결과 화면에서는 사주팔자를 제외한 영근 판정·오행 기맥·선협 재능 종합표·수련 설정만 1080×1920 PNG 파일로 내려받을 수 있습니다. 이미지 생성과 저장은 브라우저 안에서 이루어지며 클립보드나 외부 서버를 사용하지 않습니다.

## 계산 기준

### 사주 네 기둥

- 연주: 정확한 입춘 시각 기준
- 월주: 음력 월이 아닌 12절기의 절입 시각 기준
- 일주: `lunar-typescript`의 율리우스일 기반 60갑자 계산
- 시주: 현지 2시간 시진과 오서둔
- 야자시: 옵션을 켠 경우 보정된 현지 시각 23:00부터 일주를 다음 날로 계산

`lunar-typescript`의 절기 시각은 중국 표준시로 표현됩니다. 입력한 현지 시각을 Luxon으로 UTC 순간에 고정한 후 `Asia/Shanghai`의 같은 순간으로 바꾸어 Exact 연주·월주 경계를 계산합니다. 일주와 시주는 선택한 출생지의 현지 벽시계를 사용합니다.

### 진태양시

옵션을 켰을 때만 다음 보정을 현지 일주·시주 계산 시각에 적용합니다.

```text
경도 보정(분) = 4 × (출생지 경도 − 시간대 표준 자오선)
균시차(분) = 9.87 sin(2B) − 7.53 cos(B) − 1.5 sin(B)
B = 2π(연중일 − 81) / 364
```

시간대 표준 자오선은 출생 순간의 UTC 오프셋 × 15°입니다. 도시 선택값은 도시 중심 경도이므로 결과에 근사값으로 표시됩니다.

### 오행과 영근

천간, 지지 본기, 지장간은 `src/lib/bazi`의 데이터 객체로 관리합니다. 영근의 점수·임계값은 [`spiritualRootRules.ts`](src/lib/spiritual-root/spiritualRootRules.ts), 변이 조건은 [`mutationRules.ts`](src/lib/spiritual-root/mutationRules.ts)에 있습니다.

발현 모드는 영근이 존재하는 인구 비율만 바꿉니다.

- **유연 판정**: 발현 관문을 항상 개방하는 기본값(구조 통로가 전혀 없으면 무영근 가능)
- **균형 판정**: 약 15% 발현
- **엄격 판정**: 약 1% 발현

세 모드는 오행 조건값을 다르게 사용하지 않습니다. 각 오행의 천문(외부 감응), 지근(통근과 저장), 인맥(일간과의 순환)을 같은 계산식으로 평가합니다. 유연은 완성 기맥을 바로 개방하고, 균형·엄격은 태원·태식·명궁의 선천 기감 관문만 추가합니다. 생년월일시를 서버로 보내지 않으며 해시나 난수로 영근 수를 배분하지 않으므로 같은 입력은 항상 같은 결과를 냅니다. 같은 입력이 관문을 통과했다면 어느 모드에서도 같은 영근 종류가 나옵니다.

근골은 현재 영근의 발현 여부와 분리합니다. 균형·엄격 관문에서 탈락하면 실제 영근과 각성 칭호는 잠기지만, 선천 기맥 구조·순도·완성도로 계산한 근골 점수는 유연 판정과 동일하게 유지됩니다. 따라서 `근골 90 · 영문미개`처럼 높은 선천 잠재치와 미각성 상태가 함께 표시될 수 있습니다.

- **천문 天**: 투출·월령 감응·합국처럼 기운이 외부 영기와 접속하는 발현구
- **지근 地**: 본·중·여기 통근, 월지, 합국과 충손을 반영한 저장 기반
- **인맥 人**: 일간과의 생극, 생조·유통·통관을 반영한 단전 운용 통로

균형은 태원→태식→명궁의 납음이 동기·순생하고 인접 흐름에 직접 충이 없어야 합니다. 엄격은 세 보조축이 천간합·지지육합·동간·동지로 모두 연결되고, 실제 천간합·지지육합이 하나 이상이며, 충·해·파의 파손이 없어야 합니다. 50,000개 고정 검증 표본에서는 균형 13.24%, 엄격 0.994%가 발현했습니다. 순천도맥과 역천도맥은 영근 유무가 아니라 각성 후 수련 성향을 설명합니다.

오행은 먼저 **원국 구성**과 **기맥 활성도**로 나눕니다. 원국 구성은 천간 30×4, 지지 30×4의 합계 240을 지장간 수에 따라 `100%`, `70/30%`, `60/30/10%`로 나눈 설명용 구성비입니다. 이는 공인된 명리 퍼센트가 아니라 숨어 있는 재료를 0으로 지우지 않기 위한 모델입니다. 활성도는 월령의 왕·상·휴·수·사, 투출, 본·중·여기 가중 통근, 합충형파해, 성립된 생조·유통·통관을 합산합니다.

지지 본기와 지장간 본기는 활성도에서 중복 가산하지 않고, 왕지가 빠진 두 글자는 정식 반합이 아니라 약한 공합 후보로 분리합니다. 완성 영근은 천문·지근·인맥과 보존성·활성도가 모두 이어져야 합니다. 비극단 구조에서는 미약한 오행도 전체 상생망에 참여할 수 있습니다. 일반 공동 유통은 활성 2점 이상을 요구하지만, 유연 판정에서는 활성 2점 이상인 기맥 세 개가 망을 지탱할 때 활성도가 0점을 넘고 실제 통근이 남은 저점 기맥도 인정합니다. 세 완성 기맥이 별도 통로를 운반할 때는 2점 이상의 잠재근을 요구하고, 저점 실근은 네 기맥이 이미 열린 경우에만 추가 연결합니다. 0점·무근 흔적은 승격하지 않습니다. 투출만 남은 부유맥, 지지에만 머문 은근맥, 관문은 이어졌으나 힘이 부족한 봉맥은 잠재 영근으로 분리합니다.

천간합은 인접, 일간 참여, 화신의 월령·합국 지지, 원래 오행의 약한 뿌리를 모두 확인한 뒤에만 합화합니다. 조건이 부족하면 합이불화로 처리하며, 합거와 극제의 중복 감점에는 하한을 둡니다.

천영근은 주근 18점 이상, 부근 3.5점 이하, 격차 14점 이상을 모두 만족할 때만 구조적으로 응축됩니다. 변이영근은 두 유효 원재료와 생극·합, 계절, 동세, 방해 조건을 평가하며 제3의 유효 영근이 있으면 확정되지 않습니다. 5,000개 고정 결정 표본의 관측값은 다음과 같으며 표본에 따라 조금 달라질 수 있습니다.

- 천영근 1.34%
- 변이영근 3.78%
- 이영근 7.16%
- 삼영근 25.02%
- 사영근 36.36%
- 오영근 26.34%

두 원재료와 실제 융합 조건이 부족하면 변이 후보 또는 이영근으로 남습니다. 신살은 영근 개수를 바꾸지 않고 부가 성향에만 사용됩니다.

신살은 기존 화개·귀문·역마에 천을귀인·천덕귀인·월덕귀인·문창귀인·태극귀인·양인·괴강·장성·도화·겁살을 더했습니다. 기본 고전 기준은 태극귀인을 연간에서 찾고 양인을 갑·병·무·경·임 다섯 양간에만 적용합니다. 확장 기준에서는 일간 태극과 음간 제왕지를 별도의 `음인`으로 더합니다. 천을은 연간·일간, 문창·양인은 일간, 천덕·월덕은 월지를 기준으로 삼습니다.

성립한 신살은 자리와 반복 횟수로 **작용도**를, 해당 자리의 충·형·파·해로 **보존도**를 계산합니다. 보존도가 크게 무너진 길성은 재능 점수와 천도지자 같은 조합 조건에서 제외하고, 살성·혼합성은 충손 시 격동성과 위험이 커지도록 처리합니다. 전통 판정 결과를 그대로 재능 등급으로 부풀리지 않고 다음 다섯 축으로 변환합니다.

- **근골**: 영근 품질과 삼관 완성도
- **오성**: 문창·태극·화개 중심의 이해·참오·추연력
- **투골**: 양인·괴강·장성·겁살과 충형 동세
- **신혼**: 귀문·화개·태극의 정신계 감응
- **기운**: 천을·천덕·월덕의 호도·기연 성향

`천교`는 높은 근골과 오성·투골·신혼 중 하나가 함께 발달해야 하며, `천도지자`는 중첩 천을과 천덕·월덕, 네 종류 이상의 유효 길성, 실제 영근 각성을 모두 요구합니다. 고전 기준 5,000개 고정 검증 표본에서 천교 계열과 천도지자의 합계는 5% 미만이었고, 손상된 길성을 제외한 천도지자는 4명(0.08%)이었습니다. 이는 세계 인구 통계가 아니라 과잉 발생을 막는 회귀 기준입니다. 성자·도자는 재능이 아니라 종문 직위이므로 판정하지 않습니다.

사·오영근은 개수만 표시하지 않습니다. 사영근은 결핍 오행, 주도 기맥, 실제 상생 고리와 충극 강도에 따라 주근편중형·균형순생형·충극교차형 등으로 나뉩니다. 오영근은 편기주도형·충극혼탁형·순환편중형·다맥혼재형·정적균형형·오행원융형을 구분합니다. 다섯 유효 기맥에서 목→화→토→금→수→목의 실제 생조 고리 다섯 개가 모두 이어지면 오기조원영근이 되며, 점수 편차와 충극에 따라 유통·편기·탁류·원융으로 세분합니다.

오기조원은 초반에 다섯 기맥을 함께 운용해야 해 자원 소모와 정련 난도가 높지만, 완성된 상생환이 주천으로 자리 잡으면 다근의 분산을 순환 증폭으로 바꿉니다. 근골 보정은 탁류·편기·유통·원융 순으로 높아지며, 원융형은 후기 잠재력을 천영근 준급으로 평가합니다. 탁류와 편기는 충극·과성을 다스리지 못하면 같은 보정을 받지 않습니다.

수련 조언은 결핍을 새 영근으로 깨우는 방향이 아니라 주근 정련과 약근 봉쇄를 기본으로 합니다. 사영근은 빈 오행을 내적 개맥하지 않고 최약근을 줄여 삼영근화를 노리며, 일반 오영근도 약근부터 정리해 영기 분산을 낮춥니다. 결핍 계통은 법보·진법으로 외부 대응하고, 오행원융형·정적균형형·오기조원형만 다섯 기맥을 함께 보존하는 예외로 둡니다.

```text
src/
  app/                  # 입력, 결과, 해설 페이지
  components/           # 폼, 사주표, 차트, 결과 및 상세 근거

  types/                # 공통 타입
```

## 검증과 한계

검 변이영근은 목·금의 단순 공존이 아니라 두 기맥의 통근, 점수 균형, 인신충·묘유충의 절단 구조를 함께 요구하며 합성 명식과 고정 표본으로 도달 가능성과 희소성을 검증합니다.

달력 테스트에는 라이브러리 관리자가 README에 공개한 `1986-05-29` 예시(병인년·계사월·계유일), 2024년 입춘/절입 전후, 자시, 야자시, 시간대, 윤년, 2023년 윤2월, 진태양시를 포함합니다. 영근 테스트는 실제 사용자 입력이 아닌 합성 명식과 인공 오행 데이터로 0~5개 분류, 원국 구성·기맥 활성 분리, 삼관 상태, 합이불화, 잠재 영근, 오기조원, 빙·뇌·풍·용암 변이와 순천·역천도맥을 검증합니다. 추가로 태원·태식·명궁 산출, 선천 기감의 균형·엄격 관문, 관문 탈락 시에도 유연 판정의 근골 잠재치가 보존되는지, 천영근 응축이 강한 제2 기맥을 지우지 않는지, 제3 독립 영근이 변이 전에 사라지지 않는지와 품질 순서를 검사합니다. 신살 테스트는 삼합군·귀인·덕성·문성·양인·음인·괴강의 전체 기준표, 고전/확장 기준 분리, 중첩 강성, 길성 손상과 살성 격동, 유파 묶음 비활성화를 확인하고, 별도의 5,000개 표본으로 천교·천도지자의 희소성을 검사합니다.

- UI 지원 범위는 1900~2100년입니다.
- 역사적 표준시와 서머타임 정확도는 실행 환경의 IANA 시간대 데이터에 의존합니다.
- 균시차는 일반 근사식이며 고정밀 천문력은 아닙니다.
- 야자시, 신살, 합화는 명리 유파마다 기준이 다릅니다.
- 절기·시진 경계 30분 이내에는 보수적인 경고를 표시합니다.
- 규칙 점수는 세계관 설계용 초기값이며 실제 명리학적 사실을 뜻하지 않습니다.
